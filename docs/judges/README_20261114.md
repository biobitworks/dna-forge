## Challenge solution, end-to-end

1. **Intake:** five organizer packs, licensed locally, not redistributed.
   Reports: 9,010 labeled and 979 test samples, 30 criteria. Slides:
   263 total, 190 usable labeled examples and 67 held-out slides.
2. **Pretraining:** organizers supplied frozen feature vectors from
   Prov-GigaPath, H-optimus, BiomedCLIP and DINOv2. We did NOT pretrain
   or fine-tune those backbones.
3. **Task A:** parse final diagnoses, apply thirty authored criteria
   predicates; selected JSON contains valid test IDs.
4. **C1/C2 training:** shared hashed five-fold splits; locally fit
   lightweight SVM ensemble on GigaPath/H-optimus vectors; select
   organs and nearest neighbors.
5. **Controls:** kNN, logistic regression, attention-MIL, stacking,
   feature removal and supplier-domain-shift checks. Alternatives were
   weaker; preserve negative results, don't invent gains.
6. **Custody:** source hash → FCO atom and occurrence → typed FCG
   relationship → train run → derived evidence → claim → output artifact.
   The declared 23-member root recomputed; 153 declared graph edges.
   Neither proves causality; NOT_SIGNED; MMR NOT_COMPUTED.
7. **Cross-device replay:** clean pinned code and identical numerical
   environment on MagicPro and MagicStudio yielded five exact matching
   output digests. These verify bytes, not biological truth.
8. **Selected candidate:** three originally frozen files were checked
   against official organizer formats and copied to a restricted
   MagicPro snapshot at local-clock 15:16:56 PT. Original and copies
   match 3/3 digests. No answer key accessed.
