metrics and frozen VCC manifests, not chemical bioactivity. All three
container supervisors recorded clean deadline pauses (exit code 0).

drug-target screening objective; and silently injecting 24 IC50
observations violates dataset/split/endpoint gates.

**Decision:** preserve existing DAISY predecessor runs; create a
separate chemical-assay training protocol with explicit
target/assay-scaffold split, source licence, negative controls, and
claim ceiling. Next step requires a user-approved scientific target,
adequately sized and version-pinned dataset, and independent
benchmark definition. No false training claim.
